# Context Card Studio

A small Next.js app for creating accessible context cards. Edit a title and explanation in English or Kiswahili, adjust card colors, corners, and spacing, and preview hover and keyboard-focus behavior live. Saved changes stay in the current browser.

## Run locally

Install Node.js 20.9 or newer, then run `npm install` and `npm run dev`. Open http://localhost:3000.

## Deploy

Import this project into Vercel. It uses the standard Next.js App Router setup and needs no environment variables or external services.
